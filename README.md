Android launcher and lock-screen replacement, used daily as my primary home app. Gesture-driven home screen with overscroll-to-open app drawer implemented via a custom NestedScrollConnection. Lock screen intercepts screen-on events (with a grace window to ignore transient off/on cycles) and displays notifications collected through a NotificationListenerService, with swipe-to-dismiss gestures. Also includes a calendar, task management with weekly and monthly goals, live weather, and system wallpaper sync.
